# 🏗️ Piping & Structure — Project Dashboard

Fabrication & Erection ke liye complete Project Control Dashboard.

## Features
- 📅 Micro Plan — Plan vs Actual Progress (Gantt style)
- 📦 Quantity Tracking — Total Qty, Actual Qty, Balance, Qty%
- 📊 S-Curve — Cumulative Progress Chart
- 📋 DPR — Daily Progress Report with Manpower
- 👷 Resource Loading — Weekly Manpower Histogram
- 🔧 Weld Summary — Joint Register with RT Status

## Deploy on Streamlit Cloud
1. GitHub pe yeh repo upload karo
2. share.streamlit.io pe jaao
3. Repo select karo → app.py → Deploy!

## Local Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
